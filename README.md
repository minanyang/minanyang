- 🧠 On the side: [Brain](https://github.com/minanyang/brain), a Claude Code plugin that turns every coding session into a wiki the agent maintains, and [my-ai-agents](https://github.com/minanyang/my-ai-agents), my versioned agent setup.

### How I work

- **One source of truth.** One API contract, one schema, one i18n repo — shared by every app instead of copied into each.
- **Measure, then decide.** Numbers beat architectural taste.
- **Fix the class, not the instance.** A bug fix ships with whatever stops it from coming back.
- **AI-assisted, human-owned.** Agents do the typing; written rules and reviews keep them honest.
